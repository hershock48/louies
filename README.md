# Louie's Bakery

A Glazed Web rebuild of [louies-bakery.com](https://www.louies-bakery.com/), the
1952 family bakery at 144 W. Michigan Ave in Marshall, Michigan.

## Status

Research only. No build yet.

See [`docs/research-brief.md`](docs/research-brief.md) for the business background,
an audit of the current Mopro site, and where the rebuild opportunity is.

## Planned stack

Matches the other Glazed Web client builds.

- Next.js (App Router), React 19, TypeScript
- Tailwind v4
- Stripe Checkout for shipping and merch
- Resend for form email, sent from the verified glazedweb.com domain
- Deployed on Vercel

No paid third-party services baked into the site.
